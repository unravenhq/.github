### Unraven Vault

- 🔐 **End-to-end encrypted** — secrets are encrypted before they leave your machine
- 🔄 **Sync across environments** — development, staging, production
- 👥 **Share with your team** — no more `.env` files in Slack or email
- 🏢 **Built for agencies** — separate clients, projects, and access
- ⚡ **CLI-first** — pull secrets into your app in one command

```bash
brew install unravenhq/tap/vault-cli
```
